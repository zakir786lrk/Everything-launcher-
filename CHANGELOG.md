# Changelog

## 1.1.0 (Upstream Grace Launcher 1.2.4 – 1.3.0)

### Backup & Compatibility

- Unified `.zip` backup & restore format compatible with both Everything Launcher and Grace Launcher v1.3.0, plus legacy Everything Launcher `.json` restore support.

### Merged from Grace Launcher 1.3.0 & 1.2.4

### Appearance

- Expanded text shadow customization, including harder-edged shadows.

### Features

- Added support for Widget Stacks.
- Refined Private Space locking so private app processes keep running when the related option is disabled in Settings.
- Added notification replies and other notification action buttons directly on the home screen.
- Added more actions for app list swipe-left, swipe-right and double-tap gestures, such as clearing notifications.
- Added support for notifications with progress indicators.
- Added an option to remember the home screen position or always return to the first page after the screen turns off.
- Added an option to hide archived apps.
- Added backup support.
- Added an option to lock home screen scrolling.

### App list

- Added an option to align the app list height with the home screen.
- Added an option to hide symbols.

### Everything / Grace Widgets

- Fixed weather updates not refreshing promptly.
- Added separate font size controls for clock hours, minutes and seconds.
- Improved center alignment.
- Agenda entries can now show relative times instead of absolute times.
- Added an option to show overdue tasks.
- Added more actions for tapping or long-pressing the date.

### 1.2.4

- Added Tasks.org integration.
- Agenda Page now displays more details in hourly weather forecasts.
- Added support for placing one widget on Agenda Page.
- Added per-app language selection on Android 13 and later.
- Fixed minor UI issues, including home screen clock margins and font colors across Settings pages.
- Fixed animations in right-to-left (RTL) layouts.

## 1.0.0

- Initial release of **Everything Launcher**.
- Universal Spotlight Search with instant app launching and A-Z alphabet navigation rail.
- Real-time Math & percentage calculator directly in the search bar.
- Android system settings search and deep shortcuts.
- Quick AI and web search target chips (ChatGPT, Gemini, Perplexity, Claude, Google, YouTube, Reddit, etc.).
- Google News RSS feed screen with worldwide editions and topic filters.
- Contact quick actions with direct call and SMS buttons.
- Everything action button with customizable multi-gesture shortcuts.
- Auto-centering bottom dock and app stacks.
- Icon Designer with custom shapes, colors, and fallback letters.
- Customizable clock widgets and typography.
- Material You dynamic colors and AMOLED black support.
- Full backup & restore for layouts, preferences, and customizations.
- Privacy-first design: zero ads, zero analytics, zero telemetry.
